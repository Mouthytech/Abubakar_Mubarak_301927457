## Case study: Muhab Gadget Store
Muhab is a simulated online store selling gadgets: smartphones, laptops, tablets,
audio devices, wearables and accessories. The database supports customers, store
administrators, inventory staff, customer support and delivery partners. It stores
customers, products, stock, orders, payments, deliveries and reviews. Key operations
include placing orders, updating stock, processing payments and refunds, and
tracking deliveries.
